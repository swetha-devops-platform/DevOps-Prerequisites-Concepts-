VIRTUAL MACHINE: 
----------

- A VM (Virtual Machine) is a software-based computer that runs its own operating system and applications just like a physical machine. 

- It shares the physical hardware of a host system through a hypervisor. 

Components of a VM : 
-----------

- vCPU - Virtual processor
      
- vRAM - Virtual memory
      
- vDisk - Virtual storage
      
- Guest OS - Linux / Windows
      
- Applications - Software inside VM

VM Lifecycle : 
----------

- The VM Lifecycle describes all the states and stages a Virtual Machine goes through—from creation to deletion.

- In Simple Manner we can Describe the VM Lifecycle [ In point of Interview ]:


| Stage     | Description                                   |
|-----------|-----------------------------------------------|
| Create    | VM configuration and resource allocation      |
| Start     | VM boots and operating system loads           |
| Running   | VM is active and in use                       |
| Suspend   | VM is paused (state saved)                    |
| Snapshot  | Capture current VM state                      |
| Stop      | VM is gracefully shut down                    |
| Migrate   | Move VM from one host to another              |
| Clone     | Create a duplicate copy of an existing VM     |
| Delete    | Permanently remove the VM                     |


### VM Lifecycle Flow

Create → Start → Running → (Suspend / Snapshot / Stop) → Clone → Migrate → Delete
