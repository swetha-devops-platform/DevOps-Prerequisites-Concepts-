DevOps Foundations – February Learning Journey
------------------------------------------------------------------------------

This repository documents my hands-on learning and practice of core DevOps foundational concepts.
The focus of this learning phase is to build strong system administration, automation, and version control fundamentals required for a DevOps Engineer role.

Concepts Covered
---------------------------------

1. Virtualization – Understanding hypervisors, virtual machines, and environment isolation

2. Vagrant – Automated VM provisioning and reproducible development environments

3. Linux – File system, permissions, process management, package management, and system administration basics

4. Bash Scripting – Writing scripts for automation, variables, conditionals, loops, and command-line arguments

5. Networking Fundamentals – TCP/IP model, OSI model, ports, protocols, DNS, SSH, and basic troubleshooting

6. Git – Version control, branching, merging, rebasing, and repository management

Objective: 
-------------
The objective of this repository is to build a strong foundation in DevOps by mastering core infrastructure and automation concepts. 
          
Through hands-on practice in Linux, Git, networking, virtualization, and scripting, I aim to develop practical system administration skills and prepare for advanced DevOps tools such as Docker, CI/CD, and Cloud platforms.
