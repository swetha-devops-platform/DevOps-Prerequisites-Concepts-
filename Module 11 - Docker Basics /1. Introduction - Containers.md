What Exactly is Isolated Services ? 

      Isolated services are independent application components that run separately from each other, with their own runtime environment, dependencies, and resources, without affecting other services.
      

To Overcome this impact " Containers " came into an trend 


Containers : [ Process running in a directory and each dir will have an IP Address to connect eachother ]

            A container is a lightweight, standalone package that includes an application and all its dependencies so it can run consistently across different environments.

            It shares the Machines operating systems kernel and its doesn't require OS for every Applications. 

            A container is a lightweight and portable unit

            Simply it is an " Standarized unit of software " 

Example: You build an application on your laptop.

         It needs: Python, 
                   Some libraries, 
                   Specific OS version, 
                   Configuration files
         Instead of installing everything again on server…You pack everything together into one box. That box is called a " Container ".

How Containers Actually Work?

          Containers use: Linux Kernel features [ Namespaces and Cgroups ]

          These provide: Isolation which means Containers don’t see each other

                         Resource Control like CPU, RAM limits
               
                         Process Separation - Runs like separate machine


Difference Between Containers and Virtual Machine: 

Virtual Machine: A Virtual Machine is a software-based computer that runs:

                 Its own Operating System, Applications, Libraries, Virtual hardware
                 
                 It runs on top of a Hypervisor.
                 
                 Heavy and resource-consuming
  
Container: A container is a lightweight unit that: Packages application + dependencies
           
           Shares the Host OS kernel
           
           Runs as an isolated process
           
           Lightweight
