There are Concepts in Docker which we need to understand: 

Docker Hub: [central warehouse of container images] 

         Docker Hub is a cloud-based container registry provided by Docker Inc. 

         It allows users to store, manage, and distribute Docker images. It also allows to Upload images (docker push), Download images (docker pull), Share images with teams, Store private images securely

         It supports both public and private repositories and enables seamless image sharing across development, testing, and production environments.

         Just like: GitHub → stores source code and Docker Hub → stores Docker images

         Offical Website : https://hub.docker.com/


Docker Images : 

         A Docker Image is a blueprint/template to create containers.
         
         Example: nginx image → used to run Nginx server container & mysql image → used to run MySQL database container

         These images are stored in Docker Hub.


Types of Repositories in Docker Hub

1. Public Repository

         Anyone can download and it is Free

         Example: nginx, redis, ubuntu

2. Private Repository

          Only authorized users can access

          Used in companies for internal apps


Important Terms in Docker Hub


Repository	- Storage location for images

Tag	- Version of image (e.g., nginx:1.25)

Official Image - 	Verified & maintained by Docker

Push - 	Upload image to Docker Hub

Pull	- Download image from Docker Hub


Basic Docker Hub Workflow

Developer Side

                Build image:

                      docker build -t myapp .

                Login:

                      docker login

                Tag image:

                      docker tag myapp username/myapp:v1

                Push:

                       docker push username/myapp:v1
