File Permissions in Linux
-

##  What are File Permissions?

- File permissions in Linux control **who can read, write, or execute a file or directory**.

- Linux is a **multi-user system**, so permissions are used to provide security and access control.

---

# Three Types of Users in Permission

| Symbol | Meaning                     |
| ------ | --------------------------- |
| u      | User (Owner)                |
| g      | Group                       |
| o      | Others                      |
| a      | All (user + group + others) |

---

# Three Types of Permissions

| Symbol | Permission | Meaning                   |
| ------ | ---------- | ------------------------- |
| r      | Read       | View file content         |
| w      | Write      | Modify file               |
| x      | Execute    | Run file (script/program) |

---

# Example

Run:

```bash
ls -l
```

Output:

```bash
-rwxr-xr-- 1 swetha devops 1024 Feb 26 file.sh
```

Breakdown:
- rwx r-x r--
  |    |   |
  |    |   └── Others
  |    └────── Group
  └──────────── Owner
```

---

# Permission Meaning

| Section | Permission | Meaning             |
| ------- | ---------- | ------------------- |
| rwx     | Owner      | Full access         |
| r-x     | Group      | Read & execute only |
| r--     | Others     | Read only           |

---

# Numeric (Octal) Permissions

Each permission has a number:

| Permission | Value |
| ---------- | ----- |
| r          | 4     |
| w          | 2     |
| x          | 1     |

Add values:

| Permission | Number    |
| ---------- | --------- |
| rwx        | 7 (4+2+1) |
| rw-        | 6 (4+2)   |
| r--        | 4         |
| r-x        | 5 (4+1)   |

Example:

```bash
chmod 755 file.sh
```

Means:

* Owner → 7 (rwx)
* Group → 5 (r-x)
* Others → 5 (r-x)

---

#  Important Commands

## File Permission Commands in Linux

| Command | Description | Example |
|---------|------------|----------|
| `chmod` | Changes file or directory permissions (read, write, execute). | `chmod 755 script.sh` |
| `chown` | Changes file owner (user). | `chown swetha file.txt` |
| `chgrp` | Changes group ownership of a file. | `chgrp devops file.txt` |
| `ls -l` | Displays detailed file information including permissions. | `ls -l file.txt` |
