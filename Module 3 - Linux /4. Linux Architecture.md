Linux Architecture :

Linux architecture explains how the Linux operating system is structured internally and how different components interact.

It is mainly divided into 4 layers:

             Hardware Layer - CPU,RAM,Disk 
             Kernel - It interacts with hardware
             shell - it interacts with users/ application and kernel 
             users/ Application - Commands and Tool Services 
             

1. Hardware Layer

             This is the physical layer.
             It includes: CPU (Processor)
                          RAM (Memory)
                          Hard Disk / SSD
                          Network devices
                          Input/output devices
            Linux directly interacts with hardware through the kernel.

2. Kernel Layer (Heart of Linux)

              The Kernel is the core part of Linux and its manages the system Resources 
              It acts as a bridge between hardware and software.
   
Main Responsibilities:

              Function	                       Explanation
              Process Management	             Creates, schedules, and terminates processes
              Memory Management	               Allocates and deallocates RAM
              Device Drivers	                 Controls hardware devices
              File System Management	         Manages files and directories
              System Calls	                   Interface between user space and kernel

              Without the kernel, the OS cannot function.

3. Shell Layer

             The Shell is the CLI which acts as an interface between the user and the kernel.

             Examples: Bash, Sh, Zsh

             It: Accepts commands from users
                 Interprets them
                 Sends them to the kernel
                 Displays output

            When you type ls or pwd, shell communicates with the kernel.

4. Applications Layer(User Space)

            This includes: Applications
                           System utilities
                           GUI environments
                           Daemons (background services)
            Examples: Web browsers, Text editors, System tools, Server applications

            These programs use system calls to request services from the kernel.
