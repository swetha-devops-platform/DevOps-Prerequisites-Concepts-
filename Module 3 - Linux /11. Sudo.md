Sudo in Linux
-

- **sudo** stands for: **SuperUser DO**

- It allows a **normal user to execute commands with root (administrator) privileges**.

- Instead of logging in as root, we use `sudo` to run specific commands with elevated permissions.

---

Why Sudo is Important?
-

- Provides temporary administrative access
- Improves security (no need to log in as root)
- Tracks user actions (logged in system logs)
- Allows controlled access to specific commands

We use `sudo` when:
-

* Installing software
* Restarting services
* Modifying system files
* Creating users

---

# Basic Syntax

            sudo command

Example: sudo apt install nginx

Runs the command as root.

---

# How Sudo Works Internally

1. User types `sudo command`
2. System checks `/etc/sudoers`
3. If user has permission → asks for password
4. Command runs with root privileges

---

# Where is Sudo Configuration Stored?

- It should be done in /etc/sudoers

- Never edit directly using normal editor.
  
- Always use: " sudo visudo " 

This prevents syntax errors.

---

# Who Can Use Sudo?

- Only users added to:

   * `sudo` group (Ubuntu/Debian)
   * `wheel` group (RHEL/CentOS)


#  Important Sudo Commands

| Command | Description | Example |
|----------|-------------|----------|
| sudo -i | Opens an interactive root shell with root environment variables. | sudo -i |
| sudo su | Switches to root user account using sudo privileges. | sudo su |
| sudo -l | Lists the commands the current user is allowed to run with sudo. | sudo -l |
| sudo visudo | Safely edits the /etc/sudoers file with syntax checking. | sudo visudo |



# What is `su` in Linux?

`su` stands for:  **Switch User**

It is used to **switch from one user account to another user account** inside the terminal.

By default, if you type: "  su " 

It tries to switch to the **root user**.

---

# Basic Syntax

             su username

Example:su root

It will ask for the **target user's password** (not your password).


# su vs sudo (Important Difference)

| Feature           | su                             | sudo                            |
| ----------------- | ------------------------------ | ------------------------------- |
| Meaning           | Switch User                    | SuperUser Do                    |
| Password required | Target user's password         | Current user's password         |
| Usage             | Switch entire user session     | Run single command as root      |
| Security          | Less secure (full root access) | More secure (controlled access) |


# 📌 Types of su Commands

---

## `su`


* Switch to root
* Uses root password
* Does NOT load full root environment

---

##  `su -`


* Switch to root
* Loads root's environment variables
* Acts like full root login

👉 `su -` is better than just `su`

---

## Switch to Another User

```bash
su username
```

Switches to that user account.

---

# How to Come Back?

To return to previous user: type exit


# 🚀 Why sudo is Preferred Over su?

* Root password not shared
* Logs commands
* Better security
* Controlled privilege escalation
