GIT [ GLOBAL INFORMATION TRACKER ]  - INTRODUCTION
---------

- Git is a Distributed Version Control System (DVCS) used to track changes in source code during software development.

- It helps: Track code changes
          Collaborate with team 
          Maintain history
          Roll back to previous versions

GIT CREATOR :
------------------

- Before Git, Linux development used a tool called BitKeeper.

- When its free license was withdrawn in 2005, Linus decided to create a new version control system.

- Git was created by Linus Torvalds in 2005 to manage the development of the Linux kernel.

WHY GIT: 
-----------------------------
Before Git: 

 - Developers shared code manually
 - Overwriting happened
 - No proper history
 - Hard to collaborate

After Git: 

 - Version tracking
 - Branching
 - Merging
 - Collaboration

GIT ARCHITECTURE (Very Important)
-------------------------

Git has 3 main areas:

         //Working Directory  →  Staging Area  →  Local Repository//

1. Working Directory

     - Where you create/edit files.

2. Staging Area[Index]

    - Temporary area before committing

    - Controlled using: git add <file>

    - It prepares files for commit.

3. Local Repository -

     - Stores committed snapshots.

     - Controlled using: git commit -m "message"

     - git commit stores changes permanently

     - Contains full project history.
