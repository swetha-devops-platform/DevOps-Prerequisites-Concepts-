GIT SSH LOGIN :  
----------------

- Git SSH login means connecting to a remote Git repository securely using SSH keys instead of username and password.
                 
- SSH = Secure Shell
                 
- It allows encrypted communication between your system and remote Git server.

Interview based : 

- Git SSH login is a secure authentication method that uses public and private key pairs to connect to a remote repository without using a password. 

- It ensures secure and encrypted communication.
