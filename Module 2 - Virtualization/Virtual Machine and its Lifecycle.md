Virtual Machine : 

A VM (Virtual Machine) is a software-based computer that runs its own operating system and applications just like a physical machine. 

It shares the physical hardware of a host system through a hypervisor. 

Components of a VM : 

      vCPU - Virtual processor
      
      vRAM - Virtual memory
      
      vDisk - Virtual storage
      
      Guest OS - Linux / Windows
      
      Applications - Software inside VM

VM Lifecycle : 

The VM Lifecycle describes all the states and stages a Virtual Machine goes through—from creation to deletion.

In Simple Manner we can Describe the VM Lifecycle [ In point of Interview ]:


       Create	                              VM configuration & resource allocation

       Start	                                VM boots

       Running	                              Active usage

       Suspend	                              Paused state

       Snapshot	                            State capture

       Stop	                                shutdown

       Migrate	                              Move VM

       Clone	                                Duplicate VM

       Delete	                              VM removed
