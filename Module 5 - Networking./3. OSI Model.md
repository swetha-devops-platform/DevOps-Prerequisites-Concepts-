OSI LAYER - OPEN SYSTEM INTERCONNECTION MODEL : 
----

- The OSI (Open Systems Interconnection) Model is a 7-layer conceptual framework used to understand how data travels from one device to another over a network.
  
- It standardizes networking communication into layers.
  
- Its developed by ISO in 1984


Why OSI Model is Important?
-------
-  Helps troubleshoot network issues
  
-  Explains how data flows
  
-  Used in networking interviews
  
- Foundation for TCP/IP understanding
  

The Basic Elements of OSI Model Layered are, 3 Types
-------------
1. Services - It is an Set of actions that a layer offers to another higher layer 
       
2. Protocol - Protocol is a set of rules that layer uses to exchange information.
       
3. Interface - A Communication between layers
   

| Layer Number | Layer Name     | Function                                                                 | Data Unit  |
|--------------|---------------|--------------------------------------------------------------------------|------------|
| 7            | Application    | User interaction (HTTP, FTP) or Network process to application         | Data       |
| 6            | Presentation   | Data encryption, formatting, and representation                        | Data       |
| 5            | Session        | Session management or inter-host communication                         | Data       |
| 4            | Transport      | End-to-end delivery (TCP/UDP) and reliability                          | Segments   |
| 3            | Network        | Routing (IP address), path determination, logical addressing           | Packets    |
| 2            | Data Link      | MAC addressing, framing, physical addressing                           | Frames     |
| 1            | Physical       | Cables, signals, media, and binary transmission                        | Bits       |


Comparison of OSI Model and DoD (TCP/IP) Model
---------

| OSI Model Layers | DoD (TCP/IP) Model Layer | Protocols                                      | Devices                                      |
|------------------|--------------------------|------------------------------------------------|----------------------------------------------|
| Layer 7, 6, 5    | Application Layer        | DNS, DHCP, NTP, SNMP, HTTP, HTTPS, FTP, Telnet | Web Server, Mail Server, Browser, Mail Client |
| Layer 4          | Host-to-Host Layer       | TCP, UDP                                       | Gateway                                       |
| Layer 3          | Internet Layer           | IP, ICMP, IGMP                                 | Router, Firewall, Switch                     |
| Layer 2          | Network Access Layer     | MAC, ARP, RARP                                 | Bridge, Layer 2 Switch                       |
| Layer 1          | Network Access Layer     | Ethernet, Token Ring                           | Hub                                           |

Summary of the OSI Model: 
--------------
1. Physical Layer - To Transmits the bits over the medium, To provide mechanical and electrical Specifications.
   
2. Data Link Layer - To Organize bits into frames, to provide hop to hop delivery
 
3. Network Layer - To move packets from source to destination, To provide internet working

4. Transport Layer - To Provide reliable process to process messages delivery and error recovery
 
5. Session Layer  To establish, manage and terminate the session

6. Presentation Layer - To Translate, encrypt and compress data.
 
7. Application Layer - To allow access to network resources.
