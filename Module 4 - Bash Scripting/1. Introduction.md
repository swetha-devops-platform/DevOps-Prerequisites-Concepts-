What is CLI [ Command Line Interace ]:
---
- A way to interact with a computer program by typing text Commands 

What is a Shell Script?
-----
- A shell script is a file containing Linux commands executed line by line.

- Example:

   - echo "Hello DevOps"

  - date

  - whoami

What is Bash?
--------

- Bash (Bourne Again SHell) is a command-line interpreter used to:

   - Run Linux commands

   - Automate tasks

   - Write scripts for servers & DevOps pipelines
     
- In DevOps, everything runs on Linux → Bash is mandatory

Why Do We Need Bash Scripting
---------
| S.No | Advantage                          | Description |
|------|-----------------------------------|-------------|
| 1 | Automates Repetitive Tasks | Automates monitoring, backups, installations, and deployments instead of executing commands manually. |
| 2 | Saves Time & Effort | Executes multiple commands using a single script, increasing productivity. |
| 3 | Reduces Human Errors | Ensures consistent execution of commands in the same order every time. |
| 4 | Essential for Linux Administration | Used to manage users, services, files, permissions, and processes in Linux servers. |
| 5 | Core Skill for DevOps Engineers | Widely used in CI/CD pipelines, automation workflows, and infrastructure management. |
| 6 | Improves Environment Consistency | Same script can be used in development, testing, and production environments. |
| 7 | Enables Monitoring & Alerting | Helps monitor CPU, memory, disk usage, and services to detect issues early. |
| 8 | Lightweight & Cost-Effective | Preinstalled in most Linux systems with no additional cost. |
| 9 | Supports Scalability | Can be reused across multiple servers, simplifying infrastructure management. |

Why Bash is Important in DevOps (Interview Point)
---------
- Server automation

- CI/CD pipeline scripts

- Log monitoring

- Backup & cleanup jobs

- Cloud & container startup scripts
