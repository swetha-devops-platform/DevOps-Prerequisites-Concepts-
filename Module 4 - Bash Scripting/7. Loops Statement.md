LOOP 
-

- A loop is used to execute a block of code repeatedly until a condition is met.

- Instead of writing the same command multiple times, we use loops.

Why Loops are Important in DevOps?
-

In real projects, loops are used for:

- Creating multiple users

- Checking multiple servers

- Deploying to multiple environments

- Processing log files

- Automating repetitive tasks

Types of Loops in Bash
-

- for loop

- while loop

- until loop

- select loop (used for menus)

1.FOR LOOP (Most Common) - Used when you know how many times to run.Important in devops 
-

Basic Syntax

            for variable in list
            do
                 commands
            done

2.WHILE LOOP - Used when condition must be checked first.Important in devops 
-

Basic Syntax

            while [ condition ]
            do
                commands
            done


3.UNTIL LOOP - Opposite of while loop, Runs until condition becomes TRUE, runs while condition is FALSE
-

Basic Syntax

            until [ condition ]
            do
                commands
            done

Loop Control Statements
-

- break - Stops loop completely.

- continue - Skips current iteration.
