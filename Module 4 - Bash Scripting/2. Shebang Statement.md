SHEBANG STATEMENT: 
----------------
    
Shebang is a special line at the beginning of a script that tells the operating system which interpreter should be used to execute the script.
 

| S.No | Topic | Description |
|------|-------|-------------|
| 1 | Definition | Shebang is the first line of a shell script. It tells the operating system which interpreter should be used to execute the script. |
| 2 | Syntax | It starts with `#!`. These characters are called shebang (or hash-bang). |
| 3 | Example | `#!/bin/bash` |
| 4 | Purpose | Ensures the script runs using the correct shell or interpreter. |
| 5 | Without Shebang | The script may run using the default shell and can cause errors if bash-specific features are used. |
| 6 | With Shebang | Script runs consistently, avoids compatibility issues, and can be executed directly. |
| 7 | How OS Uses Shebang | OS reads the first line, finds the interpreter path, and passes the script to that interpreter. |
| 8 | Common Examples | `#!/bin/bash` (Bash shell), `#!/bin/sh` (Default shell), `#!/usr/bin/python3` (Python 3), `#!/usr/bin/env bash` (Bash from environment path). |
| 9 | Why `/usr/bin/env bash` | Finds bash from the user's environment and is more portable across systems. |
| 10 | Shebang + Execute Permission | Use `chmod +x script.sh` then run `./script.sh` to execute directly. |
