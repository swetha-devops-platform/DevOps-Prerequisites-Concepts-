Vagrant Networking : 

             In Vagrant, networking is used to control how the Virtual Machine (VM) communicates:

                            With the Host machine

                            With Other VMs

                            With the External network / Internet

Vagrant supports:

Forwarded Port - It forwards traffic from a host machine port → guest VM port  and we use it to access services running inside the VM from your local browser.

Private Network - Private network assigns a static IP to the VM for internal communication between host and other VMs.

How to increase CPU in VM : 

In Vagrant, CPU means vCPU assigned to the VM. It is taken from your laptop’s physical CPU.Usually 1 vCPU is assigned

Example : config.vm.provider "virtualbox" do |vb|

          vb.cpus = 2
          
          end

          
After Doing all the changes to the VM, we need to run the " Vagrant reload " - To changes have to save.
